# TASK_MANAGER.py

## 📌 Overview
`TASK_MANAGER.py` is a Python-based task management system that helps users organize, track, and manage tasks efficiently. It provides a simple command-line interface (CLI) for adding, updating, deleting, and viewing tasks with priority and status tracking.

---

## ⚙️ Features
- ➕ Add tasks with title, description, priority, and deadline  
- ✏️ Update tasks (status, priority, or details)  
- 🗑️ Delete tasks by ID or keyword  
- 📋 View tasks in a structured table format  
- 🔍 Search tasks by keyword or filter by status
- 💾 Persistent storage using SQL
